Headlyn is a modern news platform that turns fragmented article streams into a structured, story-first feed. It groups similar articles about the same event into one evolving story while preserving source attribution.

## Target Features

- **One story, many sources**: Related articles are grouped into a single story so users do not see the same event repeated again and again.

- **Cleaner news feed**: The feed focuses on distinct stories instead of scattered article duplicates.

- **Evolving story updates**: Stories update as new information becomes available, helping users follow events over time.

- **Personalized ranking**: The platform learns from user behavior to show more relevant stories first.

- **Better discovery**: Users still see fresh and diverse stories beyond their usual interests.

## Goal

Help users follow news with less repetition, clearer context, and more relevant story discovery.
